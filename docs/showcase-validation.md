## 已观察到的结果

1. 从张三的具体排课进入 AI 回填，输入带“模拟演示数据”标记的训练描述后，生成了待确认草稿。
2. 通过“未完成的工作 → 训练补记 → 继续”打开持久化草稿，确认后显示“正式记录已创建”。
3. 只读查询数据库确认：本展示账号新增一条正式训练记录，关联张三的本次课程；该课程为 `completed`，`session_consumed=True`，对应课时包 `used_sessions=1.0`。
4. 客户详情时间线显示臀桥、徒手深蹲和单腿站立及训练后主观反应；首页显示该课程已完成。

当前模型配置列出 `deepseek-chat`、`qwen-plus` 与 mock 备选。执行记录的 provider/model 字段为空，本次没有据此确认每次调用实际使用哪个模型，不能将截图标注成指定真实模型的效果或准确率验证。
