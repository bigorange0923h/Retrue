# Retrue 测试规范

## 最低验证要求

- 后端改动：运行 `python manage.py check`；涉及数据、权限或接口时添加并运行对应测试。
- 前端改动：运行 `npm run build`；复杂组合式函数、数据转换或关键组件应添加测试。
- 数据库改动：在 `docker compose up -d postgres` 的本地数据库执行 migration。

## 必测业务场景

| 场景 | 必须验证 |
| --- | --- |
| 权限隔离 | 康复师不能读取或修改其他康复师的客户数据 |
| AI 草稿 | AI 结果未确认前不产生正式训练、评估或阶段记录 |
| 审计 | 修改正式记录会保存修改前后内容、原因、操作人和时间 |
| 手机号 | 客户列表默认脱敏；受控编辑场景才显示完整号码 |
| 课时 | 仅在课程完成且训练记录确认保存后消耗课时 |
| 风险提醒 | 仅生成提示与待确认处理，不替代诊断或自动改计划 |

## 测试数据

- 测试、截图、日志和演示中禁止使用真实客户健康信息与手机号。
- 使用明确标记的模拟数据，例如“测试客户 A”。
