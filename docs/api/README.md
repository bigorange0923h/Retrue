# Retrue API 文档约定

每个业务域在本目录维护一个 Markdown 文件，例如 `customers.md`、`training.md`。新增或修改接口时必须同步更新对应文件。

## 统一响应

```json
{
  "code": 200,
  "message": "成功的消息",
  "data": null
}
```

## 单接口模板

```md
## 创建客户

`POST /api/customers/`

权限：已登录康复师

请求体：

```json
{ "name": "张三", "phone": "13800138000" }
```

成功响应：

```json
{ "code": 200, "message": "客户创建成功", "data": { "id": "..." } }
```

错误：`400` 参数错误；`401` 未登录；`403` 无权访问。
```

每个接口至少写明：方法与路径、权限、请求参数、成功响应、错误码、敏感字段处理和业务限制。
